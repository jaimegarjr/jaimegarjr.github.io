## Analytics

Google Analytics is enabled when `VITE_GA_MEASUREMENT_ID` is set to a GA4
Measurement ID such as `G-XXXXXXXXXX`. Add the variable to the Vercel project
for Production, Preview, and Development as needed, then redeploy.

GA4 Enhanced Measurement should remain enabled to automatically track outbound
profile clicks and resume PDF downloads.
